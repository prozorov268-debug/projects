# Java Messenger — простой серверный мессенджер

Консольный клиент-серверный мессенджер на чистом Java (JDK 17, без внешних зависимостей).

## Возможности
- Регистрация и вход (пароли хранятся в виде SHA-256 хэшей в файле `users.dat`)
- Личные сообщения между пользователями в реальном времени
- Оффлайн-доставка: если получатель не в сети, сообщение сохраняется и передаётся при его следующем входе
- Список онлайн-пользователей (`/online`)
- Системные уведомления о входе/выходе пользователей
- Многопоточный сервер: каждое соединение обслуживается отдельным потоком

## Структура проекта
```
src/messenger/
  Message.java     — модель и парсер строк протокола ("КОМАНДА:аргументы")
  UserService.java — регистрация/аутентификация, хранение хэшей паролей в файле
  Server.java      — TCP-сервер (порт по умолчанию 5000), доставка сообщений
  Client.java      — интерактивный консольный клиент
```

## Сборка и запуск
```bash
javac -encoding UTF-8 -d out src/messenger/*.java

# терминал 1 — сервер (порт можно задать аргументом):
java -cp out messenger.Server 5000

# терминалы 2..N — клиенты:
java -cp out messenger.Client localhost 5000
```

## Команды клиента
| Команда | Описание |
|---|---|
| `/register <логин> <пароль>` | зарегистрироваться и войти |
| `/login <логин> <пароль>` | войти |
| `/msg <кому> <текст>` | отправить личное сообщение |
| `/online` | список пользователей в сети |
| `/logout` | выйти из аккаунта |
| `/exit` | отключиться |
| `/help` | справка |

## Протокол (TCP, текстовые строки)
Клиент → сервер: `REGISTER:логин:пароль`, `LOGIN:логин:пароль`, `SEND:кому:текст`, `LIST`, `LOGOUT`, `QUIT`.
Сервер → клиент: `OK:текст`, `ERROR:текст`, `MESSAGE:отправитель:текст`, `SYSTEM:текст`.
