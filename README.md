# Java Messenger — простой серверный мессенджер

Консольный клиент-серверный мессенджер на чистом Java (JDK 17, без внешних зависимостей).

## Возможности
- Регистрация и вход (пароли хранятся в виде SHA-256 хэшей в файле `users.dat`)
- Личные сообщения между пользователями в реальном времени
- Оффлайн-доставка: если получатель не в сети, сообщение сохраняется и передаётся при его следующем входе
- Список онлайн-пользователей (`/online`)
- Системные уведомления о входе/выходе пользователей
- Многопоточный сервер: каждое соединение обслуживается отдельным потоком

## Структура проекта
```
src/messenger/
  Message.java     — модель и парсер строк протокола ("КОМАНДА:аргументы")
  UserService.java — регистрация/аутентификация, хранение хэшей паролей в файле
  Server.java      — TCP-сервер (порт по умолчанию 5000), доставка сообщений
  Client.java      — интерактивный консольный клиент
  ui/
    MessengerConnection.java — сетевой слой GUI: сокет + фоновый поток чтения,
                               потокобезопасная отправка команд протокола
    ClientGUI.java           — графический клиент на Swing (экраны входа и чата,
                               авто-подключение с повторными попытками)
test/
  GuiNetTest.java  — headless-тест сетевого слоя GUI (без дисплея)
```

## Сборка и запуск
```bash
javac -encoding UTF-8 -d out src/messenger/*.java src/messenger/ui/*.java

# терминал 1 — сервер (порт можно задать аргументом):
java -cp out messenger.Server 5000

# вариант A — графический клиент (авто-подключение к localhost:5000):
java -cp out messenger.ui.ClientGUI
java -cp out messenger.ui.ClientGUI myhost 6000        # явные host/port
MESSENGER_HOST=myhost MESSENGER_PORT=6000 java -cp out messenger.ui.ClientGUI

# вариант B — консольный клиент:
java -cp out messenger.Client localhost 5000
```

## GUI-клиент (messenger.ui.ClientGUI)
- **Авто-подключение при запуске** без ввода адреса. Приоритет параметров:
  аргументы командной строки → переменные окружения `MESSENGER_HOST`/`MESSENGER_PORT`
  → значения по умолчанию `localhost:5000`.
- До **3 попыток подключения с интервалом 2 секунды**; если сервер недоступен —
  сообщение об ошибке и кнопка **«Переподключиться»** (без перезапуска).
- После успешного подключения автоматически показывается экран **входа/регистрации**
  (поля «Логин», «Пароль», кнопки «Войти», «Зарегистрироваться», статус).
- Экран **чата**: список онлайн-пользователей (автоматическое обновление каждые
  10 с + по системным событиям + кнопка «Обновить список»), история сообщений
  с отправителем и временем, поле «Кому» (можно выбрать двойным кликом в списке),
  поле текста, кнопки «Отправить» и «Выйти».
- Ответы `ERROR:` показываются в статусной метке формы входа или в истории/статус-баре;
  `SYSTEM:` — в истории. При закрытии окна отправляется `QUIT` и закрывается сокет.
- Обрыв соединения во время работы: статус «Отключено» + автоматическое переподключение.
- Все сетевые операции выполняются вне EDT (фоновые потоки), изменения UI — только
  через `SwingUtilities.invokeLater`; доступ к сокету синхронизирован.

## Команды клиента
| Команда | Описание |
|---|---|
| `/register <логин> <пароль>` | зарегистрироваться и войти |
| `/login <логин> <пароль>` | войти |
| `/msg <кому> <текст>` | отправить личное сообщение |
| `/online` | список пользователей в сети |
| `/logout` | выйти из аккаунта |
| `/exit` | отключиться |
| `/help` | справка |

## Протокол (TCP, текстовые строки)
Клиент → сервер: `REGISTER:логин:пароль`, `LOGIN:логин:пароль`, `SEND:кому:текст`, `LIST`, `LOGOUT`, `QUIT`.
Сервер → клиент: `OK:текст`, `ERROR:текст`, `MESSAGE:отправитель:текст`, `SYSTEM:текст`.
